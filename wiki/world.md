## エルデ（Erde）

エルデ是一个独立存在的世界。这里的物理法则与地球相似但不完全相同——最根本的差异在于**魔力粒子（マナ粒子 / Mana Particle）**的存在。魔力粒子是エルデ世界的基本粒子之一，与物质粒子一样普遍存在。

魔力粒子驱动着这个世界的一切：从街角的魔晶路灯，到都市间穿梭的魔力鉄道；从日常生活的点火魔法，到战场上毁灭性的魔导炮。

**在エルデ，魔法不是"奇迹"——魔法是科学，是技术，是能源，是生活本身。**

---

## 東和帝国（とうわていこく / Towa Empire）

故事的主要舞台。東和帝国是エルデ最强大的人类国家之一。在过去五十年间，帝国完成了**魔法工業革命（魔法産業革命）**，国力飞速增长。

帝国的政治体制是**皇帝制与贵族制的混合体**。四大公爵家（天宫家为其中之一）在政治和军事上拥有巨大影响力。同时，随着魔法工业革命的推进，新兴的富商阶级正在挑战传统贵族的权威。

---

## 帝都·星京（せいきょう / Seikyo）

帝国最大的都市。一座魔法与蒸汽、和风与洋风交织的城市。

- **魔力鉄道（まりょくてつどう）**：城市上空的高架铁轨，列车以魔矿引擎驱动
- **魔晶灯（ましょうとう）**：街灯使用固态魔力结晶发光，白天自动吸收魔力粒子
- **工業区（こうぎょうく）**：工厂林立的区域，魔油引擎的白色蒸汽与天空融为一体
- **下町（しだまち）**：平民和下級貴族居住的区域，神代家所在地
- **皇居·貴族街**：皇室与高级贵族的居住区

## 社会階層

帝国的社会结构以**魔力**和**血统**为核心：

```
          ┌──────────┐
          │  皇  室  │
          └────┬─────┘
    ┌──────────┴──────────┐
    │  四大公爵家（上級貴族）│
    │  例：天宮家            │
    └──────────┬──────────┘
    ┌──────────┴──────────┐
    │  一般貴族（下級貴族）  │
    │  例：神代家           │
    └──────────┬──────────┘
    ┌──────────┴──────────┐
    │  平民（商人·職人·農民）│
    └──────────┬──────────┘
    ┌──────────┴──────────┐
    │  被差別階層           │
    │ （魔力障害者·異種族）  │
    └─────────────────────┘
```

**特記事項**：
- 神代家曾是下级贵族，但在零的父母去世后已实质上没落
- 天宫家是四大公爵家之一，以火属性魔法闻名

## 種族

エルデ世界的主要智慧种族：

| 种族 | 特征 |
|------|------|
| **人族（ヒューマン）** | 人口最多，支配帝国 |
| **精霊族（エルフ）** | 长寿、尖耳，拥有独立王国。魔法史比人类更悠久 |
| **獣人族（じゅうじんぞく）** | 拥有动物特征，身体强化系魔法天赋 |
| **魔族（まぞく）** | 角/特殊瞳色，暗属性魔法天赋。在帝国受到排斥，拥有自治区 |
