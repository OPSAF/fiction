## 主人公

### 神代 零（かみしろ れい / Kamishiro Rei）

| 项目 | 内容 |
|------|------|
| **年龄** | 16岁 |
| **身份** | 下级贵族·神代家现存者 / 星導学園入学考试考生 |
| **魔法等级** | F级（魔力粒子不亲和体质） |
| **外貌** | 黑发（略带蓝色光泽），深灰色眼睛。体型偏瘦。 |

**性格概要**：
冷静で理知的な性格。自分の"F級"という立場を自覚しており、卑屈にはならないが現実的に受け止めている。妹の小雪に対しては保護者的な優しさを見せる。幼なじみの朱音との掛け合いでは、淡々としたボケをかますタイプ。

幼い頃に両親を失い、現在は義妹の小雪と二人で暮らしている。魔法理論に関しては異常なまでの理解力を持つが、その理由は自分でも説明できない。

**特記事項**：
入学試験の最中、意識の中に**「端末（Terminal）」**と呼ばれるコマンドラインインターフェースを発現させる。この能力の全容はまだ不明。

## 第一章登場人物

### 天宮 朱音（あまみや あかね / Amamiya Akane）

| 项目 | 内容 |
|------|------|
| **年龄** | 16岁 |
| **身份** | 四大公爵家·天宮家の長女 |
| **魔法等级** | A级（火属性） |
| **外貌** | 深红色长发（高马尾），琥珀色眼睛。|

**性格概要**：
いわゆる**ツンデレ（傲嬌）**。零に対しては常に厳しい態度を取るが、それは彼を心配する気持ちの裏返し。貴族としての責任感が強く、弱者を虐げる者には身分を問わず立ち向かう正義感を持つ。

零とは幼い頃からの付き合いで、彼がF級であることを知りながらも、決して距離を置かなかった数少ない人物。零の前では素直になれないが、誰よりも彼のことを気にかけている。

**「べ、別にアンタのためじゃないんだからね！」**

---

### 神代 小雪（かみしろ こゆき / Kamishiro Koyuki）

| 项目 | 内容 |
|------|------|
| **年龄** | 14岁 |
| **身份** | 神代家の養女（零の義妹） |
| **魔法等级** | C级（冰属性·不稳定） |
| **外貌** | 银白色短发（波波头），冰蓝色眼睛。身型娇小。|

**性格概要**：
物静かで優しい性格。誰に対しても敬語で接し、争いを好まない。神代家の家事全般をこなし、兄·零の生活を支えることが最大の喜び。

実は神代家に引き取られた養女であり、実の両親は不明。その出自ゆえに「ここにいていいのだろうか」という不安を心の奥に抱えている。

魔力そのものは強いが、非常に不安定で制御が難しい「魔力変異」の一種を持つ。魔力が暴走すると周囲を無差別に凍結させるため、普段は魔法の使用を極力避けている。

**「お兄ちゃん、おかえりなさい。ご飯にする？お風呂にする？それとも……」**
