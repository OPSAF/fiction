## 作品概要

**《终端之梦》** 是一部融合量子力学、计算机科学与日式奇幻的轻小说。

故事发生在名为 **エルデ（Erde）** 的平行世界。这里魔法不是神秘学，而是一套成熟的**科学体系**——魔力粒子具有波粒二象性，魔法公式取代了物理定律，魔法工程学驱动着工业化。

在这个"人人都能用魔法"的世界里，主人公 **神代零** 却因体质原因成为了 **F级**——几乎无法使用任何魔法。在血统决定一切的社会中，他是那百分之三的"底色"。

然而，一场入学考试改变了一切。

零在绝境中发现，自己的意识中隐藏着一个**命令行终端**——它能直接访问并操控这个世界魔法的"底层代码"。

这不是魔法。  
这是比魔法更底层的东西。

---

## 世界観（ざっくり）

- **エルデ（Erde）**：一个与地球极为相似却又截然不同的平行世界。魔法粒子与物质并存，驱动着从街灯到铁道的整个文明。
- **魔法の科学化**：魔力粒子具有波粒二象性，遵循量子力学规律。魔法被公式化、定理化、工程化。
- **大正浪漫 × 魔法工業**：和洋折衷的城市，魔力鉄道在街道上空穿行，魔晶灯在夜晚亮起。
- **血統社会**：魔法能力的强弱由血统决定。贵族通过世代通婚维持魔力优势，"补魔装置"的研究被压制。
