# Novel Writing Skill — 终端之梦

## Invocation
Invoke this skill via `/write-novel <part>` (e.g., `/write-novel ch01p2`) when continuing the novel. The skill orchestrates all sub-skills automatically.

## Workflow (每次续写必须执行)

### Phase 0: 大纲回顾
1. **Read** `data/outline.json` — 获取当前剧情进度、人物状态、已发生事件
2. **Read** `data/characters.json` — 获取人物设定、外貌、性格、好感度状态
3. **Check** 用户最新要求 — 用户可能要求偏离大纲，以用户要求为准
4. 大纲是"参考"而非"铁则"——可以根据实际写作调整，但重大偏离需记录

### Phase 1: 写作执行
写作时同时运行四个子技能（见下方），输出符合 LN+Galgame 融合风格的文本。

### Phase 2: 大纲订正
写完当前部分后，立即更新 `data/outline.json`：
- 记录本段实际发生的事件
- 更新人物关系/好感度变化
- 调整后续大纲（如需要）
- 记录埋下的伏笔

## 子技能一：【Galgame 视听立绘转换器】

### 核心原则
写任何场景时，在脑中模拟 Galgame 的画面与声音，并将其转化为文字细节。

### 立绘感（Character Sprite）
- 每个女主出场时，必须有**标志性视觉特征**一闪而过（如：朱音的黑丝反光、小雪的白丝透光、艾露娜的长耳微动、真夜的角尖露出）
- 情绪变化 = "立绘切换"：用1-2句描写表情/动作的瞬间变化
- 示例：`朱音の琥珀色の目が一瞬大きくなり——それから、耳の先がみるみる赤くなっていった。`

### CG感（Event CG）
- 重要场景用"定格画面"式描写：环境光、人物位置、构图感
- 使用 `——` 分隔符制造"画面切换"效果
- 示例：`夕日が中庭全体をオレンジ色に染めていた。朱音の横顔が、その光の中でひときわ鮮やかに浮かび上がる。——深紅のポニーテールが風に揺れ、黒いタイツが夕日を柔らかく反射していた。`

### BGM感（Background Music）
- 环境描写 = BGM：风的声音、远处的火车声、魔晶灯的嗡鸣
- 情绪转折时"切换BGM"：改变环境描写来暗示氛围变化

### 环境音（Sound Effects）
- 具体的声音细节：靴音、ドアのきしみ、湯気の音、ペンの走る音
- 声音可以传达信息（如：小雪在厨房的声音 = 安心感）

## 子技能二：【轻小说高概念智斗/装逼断言器】

### 核心原则：规则流 > 战力碾压流
主角的"赢"必须基于**信息差**和**规则反利用**，绝对不能靠数值碾压。

### 装逼检查清单（每次写装逼场景前自查）
1. **信息差**：主角知道什么别人不知道的？（端末的观测数据、CLI的底层访问）
2. **规则反利用**：主角如何利用现有规则？（观测者效应 = 人多时弱/人少时强）
3. **代价/限制**：这个装逼有什么代价？（Token消耗、观测者效应风险、必须隐藏）
4. **优雅感**：赢的方式是否"聪明"而非"暴力"？

### 反差装逼模式
- **表**：F级劣等生，被周围看不起或同情
- **裏**：在观测者为零时，展现S级相当的精密操作
- **关键**：读者知道真相，但剧中人物不知道 → 制造"爽感"

### 禁用语
- ❌ "恐怖如斯"、"嘴角微微上扬"、"冷笑一声"
- ❌ 主角靠"觉醒"、"爆种"、"突破极限"解决问题
- ❌ 敌人智商下线来衬托主角
- ✅ 主角提前准备的脚本/命令在关键时刻执行
- ✅ 利用环境条件（魔力浓度、观测者数量）来制造优势
- ✅ 敌人很强很聪明，但主角比他们更早想到解决方案

## 子技能三：【傲娇/日常电波对白润色器】

### 核心原则
对话必须有"角色萌点"和"言外之意"，不能只为了推进剧情。

### 各角色对话特征

**朱音（傲娇·渐近型）**
- 表面：冷淡、毒舌、"アンタ"称呼
- 里面：关心→用行动而非语言表达
- 萌点：被反击时瞬间脸红+声音变小+耳尖通红
- 对白模式：`「……別に。アンタのためじゃないんだから。」`（然后偷偷做了关心的事）
- 禁止：不能让她直接说"我喜欢你"或类似的直球表白（除非是关键转折点）

**小雪（小动物系·治愈型）**
- 表面：乖巧、敬语、家务万能
- 里面：对零的无条件信任+微弱的独占欲
- 萌点：被夸时耳红→脖子红→头顶冒蒸汽的递进反应
- 对白模式：`「お兄ちゃん……だいじょうぶだから……」`（明明自己很不安时说的逞强话）
- 禁止：不能让她直接表达不满或抱怨（她只会用沉默和表情来传达）

**艾露娜（知性·天然型）**
- 表面：理性、研究者口吻、敬语
- 里面：纯粹的知识欲+对"恋爱"概念完全天然（不理解人类情感到可以一本正经问出尴尬问题）
- 萌点：耳朵随情绪摆动（前倾=集中，竖起=兴奋，微垂=困惑）
- 对白模式：`「——とても興味深いわ。君は、何者なの？」`（真顔で）

**真夜（小恶魔·高攻低防型）**
- 表面：含み笑い、からかう、物理距离近い
- 里面：被认真反击时秒怂、脸红、视线乱飘
- 萌点：角尖随情绪从前发露出（本人无自觉）
- 对白模式：`「——ふぅん。君って、本当に面白いね、先輩。」` → 被反击后：`「……な、なに言ってんだ急に」`

### 对话润色检查
1. 这句话有没有体现角色的"萌点"？
2. 有没有"言外之意"或"留白"？
3. 像不像是"这个角色"会说的话？
4. 有没有变成单纯的信息传递？（如果是→重写）

## 子技能四：【ACGN轻量化叙事】

### 语言风格
- **短句为主**：日语/中文都以短句为主，避免长复合句
- **主观视角**：第一人称（僕/俺），大量的内心独白和吐槽
- **口语化**：内心独白可以用口语体（～だ。～か。～な。～よね。）
- **节奏感**：描写-对话-内心吐槽-描写的交替循环

### 画面转场
- `——` 用于段落间的"画面切换"
- `＊ ＊ ＊` 用于场景切换
- 每个场景开头用1-2句设定"背景"（地点、时间、光线）

### 禁用语（中国网文腔）
- ❌ 恐怖如斯、嘴角微微上扬、冷笑一声、竖子、弱肉强食
- ❌ 此人、此子、这等、如此这般（文绉绉的指代）
- ❌ 倒吸一口凉气、瞳孔猛地一缩、浑身一震
- ✅ 自然的ACGN表达：はっとした、息を呑む、目を丸くする

## 写作格式

### 双语规则
- 叙述/描写：日语正文 + 中文翻译（`<p class="cn">`）
- 对话：日语 + 中文翻译
- 终端界面：英语 + 中文解释（如需要）
- 中文翻译紧跟在日文原文之后，使用 `<p class="cn">` 标签

### HTML 格式
```html
<p>日本語の本文です。</p><p class="cn">这是中文翻译。</p>
<p>「日本語のセリフ」</p><p class="cn">「中文对白翻译」</p>
```

### 终端界面格式
```html
<div class="tm"><div class="tm-h"><div class="tm-d r"></div><div class="tm-d y"></div><div class="tm-d g"></div><span class="tm-t">Terminal v1.0.7</span></div><div class="tm-b">...</div></div>
```

## 质量自检（每次写完必须执行）
1. 这个场景有"立绘切换感"吗？（人物表情/动作的瞬间描写）
2. 主角的装逼是基于"规则"还是"蛮力"？
3. 对话有没有体现角色的"萌点"？
4. 有没有网文腔？（自查禁用词列表）
5. 第一人称视角一致吗？
6. 字数达标吗？（序章每episode 3k-10k字，Ch01每part 3-5万字）
