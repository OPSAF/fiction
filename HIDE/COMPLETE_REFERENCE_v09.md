## 一、世界地理与政治格局

### 1.1 国家体系（类比地球）
| 现实类比 | 异世界 | 主体种族 | 政体 | 实力 |
|----------|--------|----------|------|------|
| 亚洲 | **東和帝国**（人类） | 人类为主，精灵/魔族受欢迎，兽族受歧视 | 君主立宪(皇帝+议会)·军阀+财阀实权 | ⭐⭐⭐⭐⭐ 最强 |
| 欧洲 | **精灵王国群**（复数王国） | 精灵为主体 | 长老议会制·森林文明 | ⭐⭐⭐⭐ |
| 美洲 | **魔族联邦**（刚经历革命） | 魔族为主体 | 联邦共和制(革命后) | ⭐⭐⭐ |
| 非洲 | **兽族诸部族联盟**（复数国家） | 兽人族为主体 | 部族联合·松散联盟 | ⭐⭐⭐ |
| 大洋洲+各地少数民族 | **离散诸族**（矮人/妖精/影民/灰鳞/深森等） | 多种族混合 | 无统一国家·散居或被驱逐 | ⭐ |

**世界总人口**：人类 > 兽族 > 精灵 > 魔族 > 离散诸族 > 上古种族

### 1.2 東和帝国（主角所在·核心舞台）
- **全称**：大東和帝国（だいとうわていこく）
- **主体民族**：人类（占85%以上）
- **文化**：日本50% + 欧洲50%混合（大正浪漫+西洋化）
- **时代感**：1920s——路面电车·蒸汽火车·瓦斯灯与魔晶灯共存·洋装与和服混杂·咖啡馆与茶室·资本主义上升期活力+封建残余
- **政体**：君主立宪制。皇帝名义上最高，但实权在军阀(天宮系)和财阀(水無瀬系)手中。
- **首都**：星京（せいきょう）——巨大都市·魔晶灯海洋·人口约500万
- **主角故乡**：星ノ宮（ほしのみや）——帝都圈外缘·人口5万·魔矿矿山镇

### 1.3 "三国轴心"（未公开的霸权构想）
東和帝国·精灵王国·魔族联邦的上层部分激进人士组成秘密联盟，意图：
- 以"上古种族正统后代"自居（人类/精灵/魔族分别自称海族/天使/龙族的后代）
- 将兽族及离散诸族视为"劣等杂种"
- 意图称霸世界（但目前只是上层构想·尚未发动战争·绝大多数平民不知情）

**重要**：这个"轴心"不是公开的政治实体。大部分普通人（包括零的同学们）对此一无所知。它只存在于上层激进派的密室中。故事中应通过暗示、侧面描写、人物对话的弦外之音来体现，而非直接说明。

### 1.4 种族歧视体系（東和帝国内部）
- **人类**：主体民族·法律上平等
- **精灵**：受尊敬（"天使的后代"）·精灵留学生在学园中受到优待
- **魔族**：受尊敬（"龙族的后代"）·但刚经历革命，部分人类对魔族有戒心
- **兽族**：受歧视（"杂种""低等生物"）·法律边缘化·经济剥削·居住隔离·"劳动斡旋"（变相奴隶制）
- **离散诸族**：更严重的歧视·几乎无法律保护

## 二、种族完整设定

### 2.1 主体种族（三国轴心·自称上古后裔）

**人类（Human）**
- 分布：東和帝国为主，世界各地均有
- 自称：海族的后代（三国官方宣传）
- 特征：魔力适性分布广（S~F级均有）。人口最多。科技与魔法融合最先进。
- 寿命：约70-80岁

**精灵（Elf）**
- 分布：精灵王国群（多个王国·长老议会制）
- 自称：天使的后代（三国官方宣传）
- 特征：长耳(8-12cm)·淡金或银色发·翡翠/紫水晶色瞳·寿命约300-500岁。天生魔力视觉——能看见魔力粒子流动。风/光属性适性极高。
- 政治：王国群之间有时有矛盾，但对人类帝国保持统一外交。

**魔族（Demon）**
- 分布：魔族联邦（刚经历"联邦革命"·联邦共和制）
- 自称：龙族的后代（三国官方宣传）
- 特征：角(种族标志·大小形状各异)·异色瞳常见·暗/火属性适性极高·寿命约200-350岁。
- 政治：革命前由暗杀家族和旧贵族统治。革命后联邦共和制成立，旧势力被清洗。

### 2.2 兽族诸部族（被歧视的"低等民族"）

兽族不是单一国家，而是复数的部族联盟/王国。被三国轴心共同视为"低等民族"。

**主要兽族分支**：
| 分支 | 特征 | 分布 |
|------|------|------|
| 猫科兽族(猫耳·猫尾) | 敏捷·夜视·独立性强 | 草原/沙漠地带 |
| 犬科兽族(犬耳·犬尾) | 忠诚·嗅觉极强·群体协作 | 温带平原 |
| 大型猫科兽族(狮/虎) | 战斗力强·领袖气质 | 热带草原·王国统治层 |
| 羽翼兽族(鸟翼) | 飞行能力·视力极强 | 高山地带 |
| 水栖兽族(鳞片·鳍) | 水中呼吸·游泳能力 | 沿海/群岛 |

**兽族国家**：约5-7个部族王国/联盟，分散在不同大陆。没有统一政权。最强大的狮王王国正在尝试统一各部族。

### 2.3 离散诸族（重新设计·不抄袭DND）

**深森族（Forest-Kin）** — 参考但不抄袭"精灵/木精灵"
- 小型人形·树皮状皮肤·头顶长苔藓/蘑菇
- 居住在古老森林深处·与自然魔力共生
- 被人类视为"森林妖怪"·常被驱逐

**灰鳞族（Ashscale）** — 参考但不抄袭"吉斯洋基人/龙裔"
- 灰白色鳞片覆盖全身·爬虫类特征·卵生
- 曾经有辉煌的沙漠帝国·现灭亡·散居世界各地
- 擅长火属性魔法·佣兵/战士为生

**影民（Shadowfolk）** — 参考但不抄袭"卓尔/黑暗精灵"
- 深色皮肤(深紫/灰黑)·白发或银发·红眼或紫眼
- 居住在地下洞穴城市·与世隔绝
- 暗属性魔法适性极高·被地表种族误解为"邪恶"
- 实际上有高度发达的文明·只是不信任地表种族

**矮人族（Dwarf）** — 经典但有修正
- 矮小结实·男性蓄须·寿命约150-200岁
- 锻造/采矿/建筑技术极其发达
- 拥有自己的山区王国·与人类帝国有贸易往来
- 在東和帝国被限制居住区域·不能拥有土地
- 土/火属性适性高

**妖精族（Fairy）**
- 小型有翼(10-30cm)·半透明翅膀
- 寿命约50-80年·繁殖快
- 魔力弱但天生能隐身
- 被人类视为"害虫"·常被驱逐或捕捉

**角民（Horned-Kin）** — 参考但不抄袭"提夫林"
- 头生双角(与魔族角不同——更粗大·螺旋状)·皮肤微红或微紫
- 魔族与人类的远古混血后代·但已被两族都遗忘
- 对魔力粒子有特殊感知力·天生魔力抗性
- 没有自己的国家·散居世界各地·普遍受歧视

### 2.4 上古种族（"雅利安"神话对应·三国崇拜但不认现存个体）

- **天使族（Angel）**：光翼·银发·极高魔力·寿命1000+年。现存极少。三国官方认为精灵是天使的后代，现存天使个体被看作"退化"。
- **龙族（Dragon）**：龙形/人形双形态·超强魔力·寿命2000+年。现存极少。三国官方认为魔族是龙的后代。
- **海族（Sea-Kin）**：水生·鳞片·深海文明·寿命800+年。现存极少。三国官方认为人类是海族的后代。

**关键**：现存的天使/龙/海族个体非常稀少（全球可能不到100人）。他们不被三国承认为"真正后代"，社会地位尴尬。

### 2.5 虚空种（Voidborn）— 世界公敌

**设计原则**：参考但不抄袭"夺心魔/Illithid"。虚空种不是外星人——它们是这个世界本身的"免疫反应"。

**设定**：
- 虚空种是世界魔力场的"异常聚集"产生的存在——当某个区域的魔力粒子密度超过临界值且持续过长时间，就会自发产生虚空种。
- 它们对所有使用魔力的生命体具有**天然的、无差别的敌意**——不是"恨"，而是像抗体攻击病原体一样的本能反应。
- 外形：没有固定形态。最弱的虚空种是黑色雾气状，中等的是扭曲的多足/多眼怪物，最强的可以拟态成任何物种。
- 极其强大——单个中等虚空种可以消灭一个没有A级以上魔法使的小镇。
- 它们正从世界各地的"魔力临界点"（古代战场遗迹/废弃魔矿/魔力污染区）不断涌出。
- 三国联盟的主要对抗目标。帝国因对抗虚空种力量不足，正在全国召集精英。

**为什么是大威胁**：虚空种的涌出频率和强度在过去50年急剧上升——与工业革命后魔矿大量开采·魔力粒子全球浓度上升有关。人类在制造自己的敌人。

| **水無瀬** | 水 | 经贸·商业·海运 | ✅ 财阀·掌控帝国经济命脉 | 水無瀬(みなせ) |
| **雷電** | 雷 | 皇帝近卫军·刑部(司法) | ❌ 皇帝失势后礼仪性存在 | 雷電(らいでん) |

| **土御門** | 土 | 帝国建筑·基建·城防 | ❌ 现代工程取代魔法建筑 | 土御門(つちみかど) |

### 天宮家（朱音所属）详细
- **本家**：帝都。掌控帝国军部
- **分家**：星ノ宮。负责魔矿品质管理+帝国纳品
- 朱音父亲：星ノ宮驻扎骑士团团长（分家当主·A级火属性）
- 朱音母亲：健在。母系血统连接到大将军
- **朱音表伯**（母亲的父亲的哥哥的长子）：现任帝国大将军——抵抗虚空种前线总指挥

## 四、魔法理论体系

### 4.1 魔力粒子（Mana Particle）
- 波粒二象性：同时具有粒子性和波动性
- 粒子面：可集聚·储存·释放·测量
- 波动面：以不同频率在空间传播·频率决定魔法属性
- 量子行为：叠加态·量子纠缠·观测坍缩
- 魔力粒子是世界的"信息载体"——魔法=读取+改写其承载的信息

### 4.2 魔力等级体系
| 等级 | 人口占比 | 说明 |
|------|----------|------|
| S级 | <0.01% | 人类极限·帝国仅数人(学园长/大将军级) |
| A级 | ~0.1% | 天才级·朱音/艾露娜/真夜 |
| B级 | ~1% | 专业魔法使·大部分魔导科教员 |
| C级 | ~5% | 中等·一般魔导科学生 |
| D级 | ~15% | 基础·日常生活魔法使用者 |
| E级 | ~35% | 微弱·仅能使用最简单魔法 |
| F级 | ~3% | **魔力粒子不親和体質**·体内无法保持魔力粒子·零的等级 |

### 4.3 魔法属性（频率划分）
| 属性 | 频率 | 颜色 | 典型用途 |
|------|------|------|----------|
| 土(Earth) | 超低频 | 琥珀 | 炼金·强化·建筑·结晶 |
| 水(Water) | 低频 | 蓝 | 治愈·流体制御·净化 |
| 风(Wind) | 中频 | 翠绿 | 通信·加速·飞行·探知 |
| 火(Fire) | 高频 | 绯红 | 战斗·能量·破坏·锻造 |
| 光(Light) | 超高频 | 金 | 结界·净化·幻术·强化 |
| 暗(Dark) | 全频带 | 深紫 | 干涉·吸收·反魔法·封印 |
| 冰(Ice) | 水+特殊变异 | 冰蓝 | 冻结·结晶化·温度控制（极稀有） |

### 4.4 魔法与血统
- 魔法才能基本由血统决定（魔力粒子亲合度是遗传性状）
- 贵族家族通过"魔法育种"维持血统强度
- 平民的魔力等级通常为D~E级
- F级=基因突变或外来者（对这个世界而言）

## 五、主角能力详解（Terminal System）

### 5.1 系统本质
- 名称：Terminal v1.0.7
- 界面：CLI（命令行界面），在零的意识视野中显示
- 语言：英语——零感觉"熟悉但无法识别"，能瞬间"翻译"，也感觉"会写"
- AI助手：Eve——机械式·功能导向·无感情
- 用户ID：KAMISHIRO_REI = Observer #7
- 激活时间：零3岁时首次接触（治愈小雪发烧）

### 5.2 可用命令
| 命令 | 功能 |
|------|------|
| `analyze` | 解析目标物质/魔力/生命体的信息结构 |
| `compile` | 将魔法逻辑编译为可执行脚本 |
| `execute` | 执行预编译的魔法脚本 |
| `monitor` | 观测周围魔力场 |
| `edit` | 编辑注册参数 |
| `search` | 搜索本地数据库 |
| `simulate` | 在隔离环境中运行模拟 |
| `status` | 显示用户状态和Token余额 |
| `help` | 显示帮助 |

### 5.3 核心限制
1. **观测者效应**：周围人数越多，终端越不稳定。0人=S级/100%，5人=B级/71%，30人=F级/41%，200+人=<8%/近乎失效。零3岁直觉感知，10岁系统性实证。
2. **Token系统**：初始1000，每日回复+50。复杂操作消耗更多。权限等级(Clearance LEVEL_1→5)随Token使用量提升。
3. **预编译要求**：突发情况不能"无中生有"。需要提前准备好可执行脚本。
4. **魔法仿真限制**：零是地球人，不能直接使用这个世界的原生魔法。只能通过终端"仿真"——效果取决于对目标魔法结构的理解深度。
5. **无人能感知**：零的F级伪装完美。没有任何角色（包括艾露娜的精灵魔力视觉、真夜的魔族感知）能看出零的终端存在。v0.8关键设定。

## 六、角色完全设定

### 神代零（Rei）— 主角
- **纯地球人**：不是任何异世界种族混血。除F级外与普通人类无异。
- **本世界无亲生父母**：16年前通过Phantasm计划被"投放"到星ノ宮诊所前。左手腕几何印记=终端接口标记。
- **前世**：地球上"林博士"——18岁博士·数学/逻辑/物理/CS/金融综合天才·Phantasm计划核心研究员·白羽栞的同班同学。记忆被隔离，仅存碎片（既视感/肌肉记忆）。
- **3岁终端觉醒**：首次使用是治愈发烧的小雪。
- **童年**：废坑狩猎·魔石收集·跨镇倒卖·床下收藏品·积蓄~7000リル。
- **个人线动机**：寻亲+Observer调查→需要资金→赚钱→赎回サラ（获取"地球"线索）

### 天宮朱音（Akane）— 第一女主
- 天宮分家长女·16岁·A+级火属性
- 父=星ノ宮骑士团长·母=健在·表伯=帝国大将军
- 10岁转学星ノ宮初等部·11岁废坑偶遇零
- 渐近型傲娇：冷淡→观察→隐约认可→"一緒に戦いたい"（六年渐进）
- 校服：深蓝水手服+红蝴蝶结+**黑色裤袜**
- 小镇唯一汽车接送·童年与同龄人交往少·努力型天才

### 神代小雪（Koyuki）— 第二女主
- 零的妹妹·14岁·冰属性C级(实际A级潜力)
- **真实身份（隐藏·永不主动揭露）**：生母=天使族（化人形），生父=人类。半天使血统→天赋来源+可使用人类用不了的魔法
- 被神代家收养·按亲妹妹描写·零和小雪都不知道天使血统
- 14岁跳级帝都特别英才学院少年班·全能型天赋怪
- 校服：**白色小腿袜**·私服：**白色裤袜**
- 萌点：被夸耳红递进·便当纸条·草莓大福·梦话敬语全掉

### 艾露娜·温德尔（Eruna）— 第三女主
