## 系统架构

### 选项类型
| 类型 | 说明 | 示例 |
|------|------|------|
| 剧情分支 | 影响后续剧情走向 | 接受/婉拒艾露娜的协助 |
| 好感度 | 影响角色好感度数值 | 与朱音对视/观察艾露娜 |
| 隐藏条件 | 需要满足特定条件才能触发 | 只有在某条件下出现的选项 |
| 信息收集 | 提供额外背景信息 | 调查某个物品 |

### 选项ID命名规则
```
chXX_[选项主题]_[序号]
```
示例：`ch01_elna_01`, `ch01_alice_deal_02`

## 选项显示规则

### 条件显示
- 选项只会在满足特定条件时显示
- 条件包括：好感度、剧情进度、之前的选择

### 选项后果提示
- 中文翻译部分会提示选项可能带来的后果
- 例如：`<span class="cs">艾露娜好感+2</span>`

### 选项样式
```html
<button class="cb a" data-c="CHOICE_ID" data-o="0">
  <span class="lt">A</span>日文选项 
  <span class="cs">中文后果说明</span>
</button>
```

## 存档系统

### 存档类型
| 类型 | 说明 | 触发时机 |
|------|------|----------|
| 自动存档 | 系统自动保存 | 进入新场景、做出选择后 |
| 手动存档 | 玩家主动保存 | 任何时候 |
| 快速存档 | 快捷键保存 | 任何时候 |
| 检查点存档 | 关键剧情点 | 选项前、战斗前 |

```json
  "timestamp": "2026-06-14T12:00:00",

  },
  "flags": {
    "accepted_elna_help": true,
    "met_alice": false
  }
}
```

## 分支管理

### 主线分支
- **朱音线**：侧重六年渐进式恋爱和天宫家的秘密
- **艾露娜线**：侧重学术研究和精灵族的秘密任务
- **小雪线**：侧重兄妹关系的变化和小雪的身世
- **真夜线**：侧重封印守护者和暗杀者的救赎

### 结局类型
| 类型 | 说明 |
|------|------|
| True End | 揭示所有真相，达成完美结局 |
| Good End | 特定角色的恋爱结局 |
| Normal End | 普通结局 |
| Bad End | 悲剧结局 |

## 特殊机制

### 观测者效应影响
- 在多人场景中，零的终端能力下降
- 某些选项需要在单人场景中才能触发

### 时间系统
- 游戏内有日夜循环
- 某些事件只在特定时间发生

### 物品收集
- 可收集魔石、文献等物品
- 某些物品解锁隐藏选项或剧情
