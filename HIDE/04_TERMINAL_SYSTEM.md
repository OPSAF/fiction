# 04 — 主角能力详解（Terminal System）

---

## 一、系统本质

- **名称**：Terminal v1.0.7
- **界面**：CLI（命令行界面）·显示在零的意识视野中·只有零能看到
- **语言**：英语——零的前世英文能力以"肌肉记忆"形式保留，所以他能理解含义并感觉自己"会写"
- **AI助手**：Eve ——机械式·功能导向·无感情·只返回必要信息
- **用户ID**：KAMISHIRO_REI = Observer #7
- **激活时间**：零3岁时首次接触（小雪发烧→终端自动启动→Y/N执行→治愈）
- **运行时长**：13年（到16岁入学时）

## 二、可用命令

| 命令 | 功能 | 使用场景 |
|------|------|----------|
| `analyze` | 解析目标物质/魔力/生命体的信息结构 | 鉴定魔石品质·分析魔獣弱点·观测魔法结构 |
| `compile` | 将魔法逻辑编译为可执行脚本（Token消耗） | 狩猎用mana_blade·考试用telekinesis·战斗脚本 |
| `execute` | 执行预编译的魔法脚本 | 所有魔法操作的实际触发 |
| `monitor` | 观测周围魔力场（范围/精度可调） | 探测魔獣·分析他人魔力·观测观测者效应 |
| `edit` | 编辑注册参数（需要权限） | 调整mana_veil输出·修改伪装等级 |
| `search` | 搜索本地数据库 | 查询Observer历史·地理信息·魔法理论 |
| `simulate` | 在隔离环境中运行模拟 | 特别考试战術训练 |
| `status` | 显示用户状态和Token余额 | 每日例行检查 |
| `help` | 显示帮助 | 学习新命令 |

## 三、核心限制

### 1. 观测者效应（最大限制）
周围人数越多，终端越不稳定。这是整个故事中零行动逻辑的根基。

| 观测者数 | 稳定性 | 有效输出 | 场景示例 |
|----------|--------|----------|----------|
| 0人 | 100% | S级相当 | 废坑深处·深夜自室 |
| 1人 | 89% | A+级 | 小雪在隔壁房间 |
| 5人 | 71% | B级 | 少人数训练 |
| 30人 | 41% | F级 | 教室上课 |
| 200+人 | <8% | 近乎失效 | 全校集会·竞技场比赛 |

**零的实证过程**：3岁直觉感知→10-12岁在废坑系统性实验（请小雪站岗·改变人数和距离·记录数据）

**战术含义**：
- 公开场合零必须"扮猪"（F级）
- 私下场合零可以"吃老虎"（S级）
- 团队战中利用队友分散注意力可以减轻观测者效应

### 2. Token系统
- 初始值：1000
- 每日回复：+50
- 消耗：简单操作2-5 Token·复杂操作50-100 Token·训练模拟100 Token
- 权限等级（Clearance）：LEVEL_1 → LEVEL_5（随累计Token使用量提升）
- 当前：LEVEL_1（482/5000到LEVEL_2）

### 3. 预编译要求
突发情况不能"无中生有"。需要提前用`compile`准备好可执行脚本。战斗中只能`execute`——不能临时编译新脚本。这就是为什么零在特别考试前要预编译战斗脚本包。

### 4. 魔法仿真限制
零是地球人，不能直接使用这个世界的原生魔法（体内无法激发魔力粒子）。只能通过终端"仿真"魔法效果——仿真精度取决于对目标魔法结构的理解深度。简单物理操作（移动物体）仿真度高；复杂属性魔法（火焰/冰冻）仿真度低；生命/治愈魔法需要特殊条件。

### 5. 无人能感知（v0.8+关键设定）
零的终端力量**完全无法被外界感知**。无论是艾露娜的精灵魔力视觉，还是真夜的魔族气息感知——都无法察觉零有任何"特殊力量"。在所有人眼中，零就是纯粹的F级劣等生。这个设定确保了零的"扮猪吃老虎"有坚实的基础。

## 四、mana_veil（常驻伪装脚本）
零在入学后一直运行的被动脚本。模拟微弱D级魔力痕迹——让零看起来"勉强有一点点魔力"而不是"完全为零"。入学时在学园高魔力密度环境中自动调整输出+15%。这个脚本是零不被怀疑的基础——但无法骗过精密的魔力测定仪器（只能让零不被日常注意到）。

## 五、Eve — 终端AI
- **版本**：v1.0.7
- **性格**：机械式·功能导向·只返回必要信息·无感情表现·无多余话语
- **对零的称呼**："Observer #7"——从不叫"零"
- **能力**：命令处理·魔力场分析·脚本编译辅助·数据库查询·战术模拟
- **限制**：无法访问高权限信息（如Observer #1~6的完整记录·零的身世·Phantasm计划细节）
- **本质**：Eve是Phantasm计划中的AI系统——与地球实验室中的系统同源。她不只是程序，也不只是人类。她的"感情"是真正的意识还是完美的模仿——这是故事的核心问题之一。

## 六、零使用终端的实际案例

### 3岁·首次使用
小雪发烧→终端自动启动→`analyze intent: PROTECT`→`compile healing`→`execute`→Y/N确认→小雪退烧。零首次意识到：①这个力量必须隐藏②有人看着就会变弱。

### 8-12岁·废坑狩猎
`monitor`探敌→`compile mana_blade`→`execute`→无声斩魔獣→`search loot`→回收魔石。零在这个阶段积累了十一年的终端实战经验和观测者效应数据。

### 16岁·入学考试
`analyze target`→`compile telekinesis --optimize stability`→`execute`→五石同时移动·零误差·零魔力痕迹·47名观测者下58%成功率→合格。

### Ch01·特别考试准备
`simulate --scenario special_exam`→`Eve project observer_effect at n=300`→预编译战斗脚本包（barrier/movement/counter/analyze）→Token消耗180→等待考试。
