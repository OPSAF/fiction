## 二、東和帝国（核心舞台）

### 2.1 概况
- **全称**：大東和帝国（だいとうわていこく）
- **主体民族**：人类（占85%以上）
- **文化基调**：日本50%+欧洲50%混合——大正浪漫+西洋化
- **时代感**：1920s——路面电车·蒸汽火车·魔晶灯与瓦斯灯共存·洋装与和服混杂·咖啡馆·工厂烟囱·资本主义上升期活力+封建残余+民主化浪潮+军国主义萌芽
- **首都**：星京（せいきょう）——巨大都市·魔晶灯海洋·人口约500万
- **主角故乡**：星ノ宮（ほしのみや）——帝都圈外缘·人口5万·魔矿矿山镇·帝都乘蒸汽火车约1小时

### 2.2 政体——二元君主立宪制
- **皇帝**：名义上最高元首·"现人神"宗教地位·实际政治权力被议会和军阀架空
- **帝国议会**：贵族院（旧贵族·五大家族残余）+ 众议院（民选·资产阶级主导）——两院制
- **内阁**：首相由议会提名·皇帝任命——实际由军阀(天宮系)和财阀(水無瀬系)轮流控制
- **实权结构**：天宮军阀（军事）+ 水無瀬财阀（经济）= 帝国的真正统治者
- **司法**：名义独立·实际上受军阀影响。雷電家曾掌管刑部·现已没落

### 2.3 货币——リル（Ril）
- 铜货：1リル·10リル
- 银货：100リル
- 晶货（魔晶铸造）：1,000リル·10,000リル
- 纸币：100リル·500リル·1,000リル·10,000リル
- 平民午餐约50リル·月收平均3,000-5,000リル·高等部学费约20,000リル/年(特待科全免)
- 帝国中央银行（水無瀬财阀控股）统一发行·魔晶储备金本位制


# 第二篇：世界历史年表

## 纪元说明
本世界使用**星暦（せいれき）**——以传说中"星之降临"（上古种族首次出现在大地上）为纪元起点。星暦元年≈约5000年前。当前为星暦318年。

## 古代（星暦前〜星暦1000年）

### 神话时代（星暦前）
- **"星之降临"**：天使族、龙族、海族从"星之彼方"来到这个世界。这是所有种族共同的神话记忆。
- 上古种族在大地上建立了第一个文明——"星之文明"。现存古代遗迹（北方山脉·星導の間·各地魔導基層論石板）均来自这个时代。
- 上古种族拥有直接操控"世界代码"的能力——即后来的"観測者"。
- **星之文明的终结**：原因不明。上古种族突然从大地上消失或大幅减少。天使/龙/海族残余个体散布世界，逐渐被后来兴起的种族视为"传说"。

### 古代王国时代（星暦1年〜1000年）
- **精灵族的兴起**（约星暦200年）：精灵在西方大陆建立起最早的精灵王国。精灵自称天使的后代，继承了部分"星之文明"的魔法知识。
- **魔族的兴起**（约星暦300年）：魔族在远隔大洋的西方大陆建立王国。魔族自称龙的后代。
- **人类的兴起**（约星暦500年）：人类在东方大陆形成部落联盟。人类自称海族的后代。
- **兽族的兴起**（约星暦600年）：兽族在南方大陆形成部族社会。兽族没有"上古祖先"神话——这是他们后来被歧视的根源之一。
- **离散诸族**（矮人/灰鳞/影民等）在这个时期各自形成小型聚落或王国。
- **虚空种首次出现**（约星暦800年）：零星的小规模涌出，被当时的上古种族残余势力压制。

### 古代文明遗产
- **魔導基層論石板**：12枚·分布在古代遗迹中·记载"世界代码"理论·"観測者"的概念首次出现
- **古代端末**：魔晶+魔法阵构成的"计算机"·零在星導学園地下図書館B5发现的那台
- **Observer #1〜#4**：古代文明中能够读写世界代码的人。#4在约星暦900年"コードを書き換えすぎた"——#3阻止了他并封印。
- **北方山脉遗迹**：与零被"投放"的地点相关·サラ部族口传中的"地球"信息源

## 中世（星暦1000年〜星暦200年·约700年前到100年前）

### 人类帝国统一战争（约星暦1800年〜2000年·约500年前到300年前）
- 人类东方大陆原本是数十个诸侯国混战状态
- **五大魔法贵族家族**在战争中崛起：天宮(火·军事)·水無瀬(水·后勤/贸易)·雷電(雷·皇帝近卫)·風間(风·情报/外交)·土御門(土·城防/基建)
- 约400年前（星暦2100年·换算为约400年前）：天宮家率领五大家族联军统一东方大陆→**東和帝国成立**
- 初代皇帝由天宮家推举——五大家族共治体制确立

### 五大家族共治时代（约400年前〜100年前）
- 天宮家：世袭帝国元帅·掌控军部
- 水無瀬家：世袭财政大臣·掌控帝国贸易和货币
- 雷電家：世袭皇帝近卫军统领·兼刑部尚书
- 風間家：世袭文官之长·帝国大学总长
- 土御門家：世袭工部尚书·帝国一切基建工程
- 兽族诸部落在这一时期被人类帝国征服或压制——兽族"低等"地位在法律上确立
- 精灵王国与人类帝国建立正式外交关系
- 魔族与人类的接触主要通过贸易和战争

### 工业革命（约150年前〜现在）
- **魔矿的发现**（约150年前）：星ノ宮矿山首次发现高纯度魔矿——能源革命开始
- **魔力发电**（约120年前）：第一座魔力发电站在帝都建成——魔晶灯普及·工厂机械化
- **魔力鉄道**（约100年前）：帝国铁路网完成——物流革命
- **资本主义兴起**：新兴资产阶级（工厂主·商人·银行家）崛起·挑战旧贵族的经济垄断
- **城市化**：星京从50万人口膨胀到500万·产业工人阶层形成
- **虚空种涌出频率上升**：与魔矿大规模开采·魔力粒子全球浓度上升有关（这是本世界"人类活动导致环境灾难"的魔法版本）

## 近代（约100年前〜现在）

### 民主化运动（约80年前〜50年前）
- **市民革命**（约80年前）：资产阶级联合市民阶层发动"立宪运动"·要求限制皇权和贵族特权
- **帝国宪法颁布**（约75年前）：君主立宪制确立·帝国议会成立·贵族院+众议院两院制
- **五大家族的衰落**：
  - 天宮家：军阀化转型——交出部分政治权力但保留军事控制·成为"国中之国"
  - 水無瀬家：与新兴资本家合作→转型为财阀·掌控帝国银行和主要产业
  - 雷電家：皇帝失势→近卫军解散→沦为礼仪性存在
  - 風間家：教育权归国家→帝国大学国有化→仅存名誉
  - 土御門家：现代工程取代魔法建筑→家族产业破产→没落
- **义务教育制度**（约60年前）：初等部6年+中等部3年·全国推行

### 魔族联邦革命（约30年前〜15年前）
- **旧魔族王国**：由暗杀家族和旧贵族统治的专制政体·极度不平等
- **革命爆发**（约30年前）：魔族民众起义·联邦共和派领导
- **内战**（约30年前〜20年前）：持续约十年·联邦共和派最终胜利
- **旧势力清洗**（约20年前）：暗杀家族被取缔——部分被联邦暗部秘密收编·大部分被处决或流放
- **黒鉄一族**：真夜的家族——父母在革命中牺牲·真夜幼时（约3-5岁）被带离魔族联邦
- **联邦共和国成立**（约18年前）：魔族联邦正式成为联邦共和制国家
- **与人类帝国的关系**：革命后联邦与帝国关系一度紧张——后因共同对抗虚空种而改善

### 精灵王国群的政治演变
- 精灵王国群是复数的精灵王国的松散联盟·由长老议会协调外交和军事
- 与人类帝国保持长期外交关系·互派留学生
- 精灵族内部对"与人类结盟"有分歧：保守派认为精灵应保持独立·进步派认为对抗虚空种需要团结
- 艾露娜的派遣=进步派长老推动的"亲人类"政策的一部分

### 三国轴心的形成（约10年前〜现在·未公开）
- 東和帝国·精灵王国·魔族联邦的上层激进人士秘密联盟
- 背景：虚空种威胁加剧·三国都需要更多的军事和魔法资源
- **轴心理念**：
  - 人类/精灵/魔族=上古种族正统后代（海族/天使/龙族）→"高等民族"
  - 兽族/离散诸族=没有上古祖先的"劣等杂种"
  - 意图：联合称霸世界·瓜分兽族领土·控制全球魔矿资源
- **现状**：目前只是上层构想·尚未发动战争·绝大多数平民完全不知情
- 帝国内部对轴心有分歧：军阀(天宮系)主战·财阀(水無瀬系)担心战争影响贸易·皇帝反对（但无实权）

### 虚空种危机（最近50年·持续恶化）
- 涌出频率和强度急剧上升→直接原因是工业革命后魔矿大规模开采导致魔力粒子全球浓度上升
- 帝国已有多座边境城镇被虚空种摧毁→帝国军部（天宮系）借机扩大军备
- 对抗虚空种是帝国"召集全国精英"的公开理由——也是小雪被高层注意、零被招入特待科的深层原因


# 第三篇：政治与权力结构

## 一、帝国内部派系

### 1. 天宮军阀（军事派·鹰派）
- **核心**：天宮家本家+军方高层
- **主张**：扩军·对抗虚空种·支持三国轴心·"先发制人"战略
- **代表人物**：帝国大将军（朱音表伯）
- **民意基础**：虚空种威胁带来恐慌→军方借机扩大影响力

### 2. 水無瀬财阀（经济派·鸽派）
- **核心**：水無瀬家+帝国银行+主要产业资本家
- **主张**：自由贸易·稳定优先·对轴心持保留态度（战争影响贸易）
- **代表人物**：水無瀬家当主（兼任帝国银行总裁）
- **民意基础**：资产阶级和城市中产阶级

### 3. 皇帝派（保守派·弱势）
- **核心**：皇室+雷電/風間/土御門残余+部分旧贵族
- **主张**：恢复皇权·抵制军阀和财阀·维护传统
- **代表人物**：现皇帝（年迈·政治影响力有限）
- **民意基础**：农村地主·保守知识分子

### 4. 民主派（改革派·新兴）
- **核心**：众议院部分议员·知识分子·记者·工会
- **主张**：扩大民主·废除贵族特权·改善劳动者待遇·反对轴心扩张
- **代表人物**：众议院中少数派
- **民意基础**：城市知识分子·部分工人

### 5. 星導学園（学术/研究派·相对中立）
- 学園は帝国の魔法研究の中枢·正式には帝国の機関だが、政治的には相対的中立
- 理事会メンバーは各派閥から派遣——内部にも派閥対立がある
- 零を"観察対象"として入学させたのは理事会内の天宮系メンバーの判断（軍閥が新しい"兵器"候補を探している）

## 二、法律与制度

### 2.1 义务教育制度（星暦270年〜·约50年前确立）
- 初等部6年（6-12岁）+ 中等部3年（12-15岁）= 9年义务教育
- 中等部から普通科と魔導科に分岐（D级以上=魔導科）
- 高等部（星導学園等）= 2年基础+3年专门研究+可选研究部
- 学費は家庭負担だが、特待科は全額免除（国家が人材を囲い込む仕組み）

### 2.2 奴隶制/劳动斡旋制度
- **表向き**：奴隶制は約100年前の民主化時に"廃止"
- **実際**："労働斡旋"という名目で亚人种（主に兽族）の半强制労働が横行
  - 戦争捕虜·債務不履行者·"保護された"辺境出身者——名目上は"契約労働"
  - 実際は人身売買に近い——特に工場地帯で深刻
  - 法律のグレーゾーン：契約書があれば"合法"·しかし契約は多くの場合強制的
- **サラのケース**：魔晶精炼工場で"契約労働"——実質的な奴隶·高額の"違約金"設定で逃げられない
- **社会的態度**：多くの帝国市民はこの制度を"仕方ない"と黙認·一部の改革派が廃止を訴えている

### 2.3 亚人种歧视法
- 明文化された差別法は少ないが、慣習法や行政規則で差別が制度化
- 兽族の居住区域制限·職業制限·結婚制限（人間との結婚は認められない）
- 精灵·魔族は"高等种族"として差別対象外（ただし人間より下に見る者もいる）
- 离散诸族：ほぼ無保護·法的に"存在しない"扱い

## 三、军事

### 3.1 帝国軍の構成
- **常備軍**：約30万人·天宮家が実質的に指揮
- **騎士団**：各地に配置された魔法戦士部隊·星ノ宮にも駐在（朱音の父が団長）
- **対虚空種専門部隊**："虚討隊"——最精鋭·帝国大将军直属
- **徵兵制**：18歳以上の男子に2年間の兵役義務（学生は猶予·貴族は免除可能）

### 3.2 星導学園の軍事的役割
- 学園は魔法戦士の育成機関としての側面も持つ
- 卒業生の多くは帝国軍に入隊
- 特別試験は軍事的適性を測る目的もある（学生には知らされていない）
- "星導の間"には古代兵器に関する情報があると噂される


# 第四篇：经济与社会

## 一、经济结构

### 1.1 主要産業
- **魔鉱採掘**：帝国の基幹産業·星ノ宮は五指に入る産地
- **魔晶精煉**：魔鉱→魔晶（高纯度魔力結晶）·帝都郊外工業地帯に集中
- **魔力発電**：魔晶を燃料に発電·帝国全土のエネルギー供給
- **魔法道具製造**：武器·防具·生活用品·産業機械
- **農業**：魔力で強化された農業（温暖化·成長促進）·農村はまだ広い
- **鉄道·海運**：水無瀬财阀がほぼ独占

### 1.2 階級構造（1920s）
| 階級 | 人口比 | 特徴 |
|------|--------|------|
| 旧贵族（五大家族等） | <1% | 政治力は衰退·土地所有と名誉は保持 |
| 新興資本家（財閥·工場主·銀行家） | ~3% | 経済的実権·水無瀬系と連携 |
| 中産階級（商人·教師·下級官僚·技術者） | ~15% | 都市部で成長中·民主化の支持基盤 |
| 労働者階級（工場労働者·鉱山労働者） | ~40% | 都市部·労働条件は劣悪·工会運動萌芽 |
| 農民 | ~35% | 地方·伝統的生活·政治参加ほぼなし |
| 亚人种 | ~6% | 法的保護なし·最底辺·"労働斡旋"の対象 |

### 1.3 零の経済状態
- 養父の月収：約2,500リル（下級公務員）
- 養母のパート収入：約800リル
- 家計月収合計：約3,300リル——帝国平均よりやや低いが、安定している
- 零の個人的蓄え：約7,500リル（11歳時点·廃坑冒险+倒卖で蓄積）
- 特待科入学後：学費·寮費全免＋生活費補助あり——経済的心配はなし

## 二、宗教と信仰

### 2.1 星教（帝国国教）
- 上古种族（天使·龙·海族）を"星から来た神々"として崇拝
- "星之降临"神話に基づく·皇帝は天使の"代理人"とされる
- 現実には形式的な信仰が多く·熱心な信者は少ない
- 大祭（星祭り）は年に一度·帝都で盛大に開催——Ch05の舞台

### 2.2 民間信仰
- 地方ごとに多様な精霊信仰·祖先崇拝が残る
- 鉱山町では"山の神"信仰が強い（星ノ宮も）
- 魔法使いの間では"魔力場そのものが意志を持つ"という汎心論的な考え方も

### 2.3 "进化论"信仰
- 三国轴心的イデオロギー的基盤
- 天使→精灵 / 龙族→魔族 / 海族→人类 ——この"进化"を信じることが"文明国"の証とされる
- 兽族には"上古祖先"がいないため、"进化の過程で取り残された"と蔑視される
- 学术界では批判も多いが、政治的には"正しい"とされる

## 三、教育体系（详细）

### 3.1 初等部（6年·6-12岁）

- 魔法の才能がある子は放課後の特別クラスで実技練習
- 入学時に魔力検査（零はここでF級判定）

### 3.2 中等部（3年·12-15岁）
- 普通科と魔導科に分岐（D级以上=魔導科）
- 普通科：一般教養·基礎理論·実技なし
- 魔導科：高度魔法理論·実技訓練·戦術基礎

### 3.3 高等部（2-5年·星導学園等）
- 高等部（2年）：基礎課程·一般教養+専門基礎
- 専門部（3年）：専門研究·卒業論文
- 研究部（オプション·2-3年）：高度研究
- 特待科：学費·寮費全免·最難関·エリートコース

### 3.4 帝都特別英才学院（少年班）
- 小雪が通う学校·星導学園の隣
- 飛び級·超優秀児童向け·全国から選抜
- 実質的には帝国の"天才囲い込み"機関

# 第七篇：文化与社会细节（写作时可随时参考）

## 一、日常生活
- **食**：和食为主——米·魚·味噌汁·漬物。都市部でパン·コーヒー·洋菓子普及中。平民の昼食は50リル程度。
- **衣**：洋装（スーツ·制服·ドレス）と和服（着物·浴衣）が混在。学生は制服。貴族は洋装が正式·和服は私的場面。
- **住**：都市部=煉瓦造アパート·木造長屋。地方=木造一戸建て。贵族=洋館。星ノ宮=鉱山労働者向け長屋が多い。

- **照明**：魔晶灯（都市部·公共施設·富裕層）。蝋燭·油灯（地方·貧困層）。
